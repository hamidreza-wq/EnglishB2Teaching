# English B2 Academy 0.2.1

Early usable Windows x64 learning release, 2026-11-06.

## Delivered

- Native WPF app with per-user MSI setup, included .NET runtime, Start menu/
  optional desktop shortcuts, major upgrades and Windows Installer uninstall.
- 35 original A1-B2 short lessons and 105 marked lesson questions.
- 30 original vocabulary flashcards with recall-based review scheduling.
- Limited grammar/vocabulary diagnostic, recommendations, mistake notebook,
  transparent attempt history and real progress charts.
- Separate 30-question timed original practice bank, persisted countdowns and
  post-submission review.
- Writing drafts and timed two-task writing; no automatic quality marking.
- Original reading/listening materials, local speech controls and permission-gated
  optional WAV recording/playback/deletion for speaking.
- SQLite storage, schema checks, daily startup backups, validated restore,
  local JSON export and confirmed learning-record deletion.
- Save view/F12 captures the real current screen as a local PNG.

## Verification

30 automated checks pass. MSI installation and an actual 0.2.0 -> 0.2.1 upgrade
succeeded. Upgrade preserved the learning database unchanged.
See [detailed verification and limits](TEST_REPORT.md).

## Important limitations

This is not the complete system from the product brief. The course collection is
introductory; the mock is shortened, not a full official-format paper.
Writing/speaking are self-review activities. No official scale score, certified
CEFR estimate, exam readiness decision or pass guarantee is generated.
Other exam-board pathways and imported historical papers are not available.
Independent content review, hardware audio testing, uninstall testing, clean-VM/
ARM64 testing, signing and automatic updates remain outstanding.

No paid API, account or ongoing subscription is required. Installed Windows fonts
and speech voices remain subject to Windows platform terms.
